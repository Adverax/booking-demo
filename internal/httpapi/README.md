# httpapi

## Purpose

The HTTP API of the booking service (COMP-001). The types and the `net/http` server interface are generated from the contract [`api/openapi.yaml`](../../api/openapi.yaml) (contract first, ADR-0009). `NewHandler` mounts the generated routes on `http.ServeMux` and makes every failure that happens before or around a handler answer in the contract's JSON error shape. The package holds no handler logic: each behaviour's handler is written by the card that owns it.

## Architecture

- `api.gen.go` is generated by oapi-codegen (std-http and strict server, settings in [`oapi-codegen.yaml`](./oapi-codegen.yaml)). The generator version is pinned by the `tool` directive in `go.mod`. Regenerate with `go generate ./internal/httpapi`; never edit the file by hand. `TestContract_GeneratedCodeMatchesSpec` fails on any drift between the spec and the generated code.
- Handlers implement `StrictServerInterface` and return the generated response types. A status or body the contract does not declare therefore does not compile.
- `NewHandler` maps failures to the contract's errors:
  - unknown or non-canonical paths go to 404 `not_found`, with no redirect;
  - a wrong method goes to 405 `method_not_allowed`, and the `Allow` header is kept;
  - a body larger than 1 MiB goes to 413 `request_too_large`;
  - a body that is not exactly one JSON value, or a parameter that cannot be bound, goes to 400 `validation_error`;
  - a handler error or panic goes to 500 `internal_error`, and the error text is not returned.
- Schema keywords such as `minLength`, `pattern` and `enum` are declarative contract. There is no runtime schema validator, and kin-openapi is used only in tests. The domain cards enforce those rules and answer `validation_error`.
- The package depends only on the generated code and `github.com/oapi-codegen/runtime`. It does not import the store or any domain package.

## Key entities

| Name | Kind | Description | File |
|------|------|-------------|------|
| `NewHandler` | func | Mounts the generated routes on `http.ServeMux` behind the contract's error mapping | [`server.go`](./server.go) |
| `StrictServerInterface` | interface | One method per operation of the contract; implemented by the handler cards | [`api.gen.go`](./api.gen.go) |
| `ErrorCode` | type | The stable error codes, declared once in the spec | [`api.gen.go`](./api.gen.go) |
| `Error` | type | The JSON error body `{code, message}` | [`api.gen.go`](./api.gen.go) |

## Usage

```go
// impl implements httpapi.StrictServerInterface.
srv := &http.Server{Addr: ":8080", Handler: httpapi.NewHandler(impl)}
```
